# Свой путь — Хабаровский край

Небольшой информационный сайт из трёх страниц: главная, результаты опроса и возможности для молодёжи.

Статический HTML/CSS, без сборки и внешних зависимостей. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Опрос: 15 добровольных ответов школьников 21–22 сентября 2026 года. Дата среза — 22 октября 2026 года. Результаты описывают только опрошенную группу.
